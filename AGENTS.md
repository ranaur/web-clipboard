# Agent Instructions — Distributed Clipboard

## Project Overview

This repository implements a **Distributed Clipboard**: a browser-first, cross-platform application that lets users share text, images and files between devices using a 3-word BIP-39 identifier. The server only relays and stores encrypted data — all cryptography happens in the client.

The full architecture and tech-stack specification is in <ref_file file="ARCHITECTURE.md" />.

## Tech Stack

- **Client**: TypeScript, vanilla Web APIs, Web Crypto API, IndexedDB, WebSocket, Clipboard API.
- **Server**: Node.js 20+, Express, `ws` library, flat-file storage.
- **Build**: Vite for the client, `tsc` for the server.
- **Tests**: vitest for client, Node Test Runner for server.
- **Lint/Format**: ESLint + Prettier.

## Coding Conventions

- Use **ES modules** (`"type": "module"` in `package.json`).
- Prefer **strict TypeScript** with `noImplicitAny` and `strictNullChecks`.
- Never implement cryptographic operations on the server with plaintext data.
- All secrets, keys and the shared secret live in the browser.
- Keep dependencies minimal; prefer native APIs over large libraries.
- Use Base64 for transmitting binary data; use `Uint8Array` for internal crypto operations.
- Do not log keys, signatures or ciphertext metadata in production.

## Key Rules

- Clipboard identifiers are three random BIP-39 words joined by dashes.
- Each device creates a public/private key pair on first load.
- Key storage uses IndexedDB; if a password is set, wrap the private key with AES-256-GCM using PBKDF2.
- New clients must pass a public-key challenge and be approved by an owner.
- The shared secret is generated by the first connected client and distributed encrypted with each member's public key.
- All clipboard content is encrypted with the shared secret using AES-256-GCM before leaving the client.
- When the last client disconnects, delete the `content/` directory; keep only `meta.json` for a TTL.

## Common Commands

```bash
npm install
npm run dev          # start server + Vite dev server
npm run build        # compile server and bundle client to dist/
npm start            # run production server from dist/
npm run typecheck    # TypeScript check
npm run lint         # ESLint
npm run format       # Prettier format
npm run format:check # Prettier check
npm test             # run all tests
```
